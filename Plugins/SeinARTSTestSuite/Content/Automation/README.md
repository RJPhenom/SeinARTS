# Automation assets

Keep tiny framework-only test maps, Blueprints, and data assets beneath this directory. Prefer code
fixtures; assets belong here only when a test requires Blueprint compilation, actor construction,
baked level geometry, rendering, or replication. Squad, Cover, Movement+, and cross-extension
assets belong in the sibling `SeinARTSExtensionTestSuite`. Generated bake data and Automation
reports are not source assets.
