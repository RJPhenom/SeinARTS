	<section class="sein-home-core" aria-labelledby="sein-home-core-title">
		<div class="sein-home-section-inner">
			<h2 id="sein-home-core-title">Build on a deterministic core</h2>
			<p>SeinARTS separates authoritative simulation from presentation so the game state can remain reproducible across peers while Unreal Engine handles rendering, input, and authoring.</p>

			<CardGrid stagger>
				<Card title="Deterministic by design" icon="setting">
					Fixed-point simulation, canonical state, and lockstep configuration are foundational contracts rather than optional modes.
				</Card>
				<Card title="Designer authored" icon="pencil">
					Units are Blueprint classes, components are data, and commands such as move or attack are composed as abilities.
				</Card>
				<Card title="Modular extensions" icon="add-document">
					Add squads, cover, movement modes, or online services without making the core framework depend on them.
				</Card>
				<Card title="One-way presentation" icon="document">
					Simulation state flows into rendering. Presentation can react to the simulation, but it never feeds authoritative state back into it.
				</Card>
			</CardGrid>
		</div>
	</section>
